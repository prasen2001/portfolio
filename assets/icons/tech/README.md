# Technology icons

The general technology SVG brand assets in this folder come from the [Devicon](https://github.com/devicons/devicon) and [Simple Icons](https://github.com/simple-icons/simple-icons) projects. The AWS service SVGs come from the official [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/) package. Google Cloud service SVGs come from the official [Google Cloud icon library](https://cloud.google.com/icons), using current core icons where available and legacy console icons for the remaining services. The Pinecone mark comes from Pinecone's official website, the Nebius mark comes from the official [Nebius media kit](https://nebius.com/media-kit), and the Docling mark comes from the official [Docling repository](https://github.com/docling-project/docling). All icons are stored locally so the portfolio does not depend on a third-party CDN at runtime.

Devicon provides original and plain SVG variants for development technologies. AWS SAM uses the official AWS CloudFormation architecture icon because SAM is a framework that transforms into CloudFormation rather than a standalone AWS service. Brand names and logos remain trademarks of their respective owners. Custom conceptual icons such as AI Agents, RAG, React Flow, SQL, and CI/CD remain embedded in `script.js` because they do not map cleanly to a single official product mark.
