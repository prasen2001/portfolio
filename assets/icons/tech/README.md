# Technology icons

The SVG brand assets in this folder come from the [Devicon](https://github.com/devicons/devicon) project and are stored locally so the portfolio does not depend on a third-party CDN at runtime.

Devicon provides original and plain SVG variants for development technologies. Brand names and logos remain trademarks of their respective owners. Custom conceptual icons such as AI Agents, RAG, React Flow, SQL, and CI/CD remain embedded in `script.js` because they do not map cleanly to a single official product mark.
