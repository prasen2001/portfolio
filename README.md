# Prasenjeet's portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript.

## Preview locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Add resume content

All personal content lives in `resume-data.js`. Public documents and images are organized under `assets/`; see `assets/README.md` for the folder structure and publishing guidance.
